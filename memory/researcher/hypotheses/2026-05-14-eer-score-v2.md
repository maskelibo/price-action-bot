### 3.2 Hierarchical Fallback (3 seviye)

```python
def compute_eer_v2(trade, history, ctx, cfg):
    # Level 1: tam bucket
    bk1 = (trade.strategy, trade.symbol, regime, atr_bucket)
    bucket_rs_1 = [h.R for h in history if matches(h, bk1)]
    if len(bucket_rs_1) >= cfg.sample_min:
        return percentile_rank_shrunken(bucket_rs_1, global_avg, k=20)

    # Level 2: symbol drop
    bk2 = (trade.strategy, regime, atr_bucket)
    bucket_rs_2 = [h.R for h in history if matches(h, bk2)]
    if len(bucket_rs_2) >= cfg.sample_min:
        return percentile_rank_shrunken(bucket_rs_2, global_avg, k=20)

    # Level 3: atr drop
    bk3 = (trade.strategy, regime)
    bucket_rs_3 = [h.R for h in history if matches(h, bk3)]
    if len(bucket_rs_3) >= cfg.sample_min:
        return percentile_rank_shrunken(bucket_rs_3, global_avg, k=20)

    # Final fallback: strategy avg
    bucket_rs_4 = [h.R for h in history if h.strategy == trade.strategy]
    if len(bucket_rs_4) >= 10:  # daha gevsek (lvl 4)
        return percentile_rank_shrunken(bucket_rs_4, global_avg, k=20)

    return 0.50  # tier-cuts ile T2'ye duser
```

### 3.3 Bayesian Shrinkage

Bucket avg_R, sample boyutuna gore global avg_R'ya cekilir (sample az → guvenmiyoruz, global'a yaklas):

```
shrunken_avg = (n * bucket_avg + k * global_avg) / (n + k)
```

- n = bucket_rs sayisi
- k = 20 (pre-registered)
- global_avg = lookback penceresindeki TUM trade'lerin avg_R'si

**Mantik:** n=30, k=20 → shrinkage 40% global. n=100, k=20 → shrinkage 17%. n=1000 → ~%2.
Bu, kucuk sample'lardaki gurultuyu bastirir; **clustering bias** ve **fluky bucket** etkisini azaltir.

Percentile rank, shrunken_avg uzerinden hesaplanir.

### 3.4 Edge-Gate Sizing (Analyst Input)

```python
def apply_eer_sizing(trade, lookback_trades, cfg):
    # Per-window EER tier hesapla
    top_R = mean([t.R for t in lookback_trades if t.eer >= 0.80])
    bot_R = mean([t.R for t in lookback_trades if t.eer <= 0.20])

    if len(top_pool) >= 30 and len(bot_pool) >= 30 and bot_R > 0:
        edge_ratio = top_R / bot_R
    else:
        edge_ratio = 1.0  # not enough data, default 1

    if edge_ratio >= 3.5:
        # Real edge — use tier sizing
        tier = eer_to_tier(trade.eer)
        return TIER_SIZING[tier]
    else:
        # No real edge — flat T2 (%2 risk, 2x lev)
        return TIER_SIZING[2]
```

**Pre-window edge measurement:** in-sample (training) data'da edge_ratio hesapla; OOS'da uygula. Look-ahead engellenir.

### 3.5 Sample-Size Gerekceleri (TUM SAYI)

- **lookback_days = 365**: v1'de 180 yetmedi (bucket coverage 0). 1 yil = full crypto cycle (BTC halving sub-phase). Trade pool 4787/5y → 957 trade/yil ortalama. 4-dim bucket 1772 unique (v1) → 4-dim cinsinden ~500 unique tahmini. Per bucket ortalama 957/500 = 1.9 trade/yil; 365-gun rolling ile cumulative >30 ulasilabilir senior bucket'larda (en cok kullanilanlar).

## 8. Karsi-Hipotezler

**KH-1: 4-dim hala fazla genis.**  10 strat × 11 sym × 3 regime × 3 atr = 990 olasi bucket. 4787 trade ile per bucket ortalama 4.8. 365-gun rolling = ~%20'lik dilimi (yaklasik 957 trade) → per bucket 1 trade. Hierarchical fallback level 2-3 ile coverage gelir ama L1 coverage <%10 olabilir. RED kosulu coverage <%30.

**KH-2: Hierarchical fallback signal dilution.**  Level 3'te (strategy, regime) coarse — bu noktada percentile rank curve fit. Edge-gate koruyacak ama edge gate'in kendisi de in-sample veriden. Robustness: per-level reporting + level distribution gate (L4 <%30).

**KH-3: Edge-gate test set leakage.**  Edge ratio in-sample'dan hesaplaniyor; OOS'a uygulaniyor. Bu causal. Ama in-sample edge orani 3.5x ise OOS'da da 3.5x olmayabilir (regime shift). Robustness: per-window edge_ratio actual report + Spearman correlation (in-sample edge ratio vs OOS edge ratio).

**KH-4: Shrinkage k yarisindan az → curve fit.**  k=20 ile robustness check'te k=10, 40 calistirilir. Eger k=20'nin alpha'si en yuksek ise rolc-fit suphesi var. Pre-registered: k=20 default — eger k=10 veya k=40 alpha daha yuksek ise pre-reg ihlali (red).

**KH-5: Flat T2 baseline kendisi CONF tier'i yener (v1 yan-bulgu) — alpha v2'nin degil, CONF'un kotuluginden.** Cozumu: v1'de gosterildi ki tier-uniform T2 zaten DYNAMIC v0.9.8'i yener. v2'nin **ek delta** vermesi gerekir flat_T2 baseline UZERINE. Sadece "EER > CONF" yetmez; "EER_v2 > flat_T2_baseline" gerekli.
